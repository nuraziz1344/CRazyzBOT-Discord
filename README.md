# GO discord music bot
discord music bot written in go programming language

## Requirements
- [GO](https://go.dev)
- [FFMPEG](https://ffmpeg.org)

## Installation
```bash
# clone this repository
git cone https://github.com/nuraziz0404/go-discord-music.git
cd go-discord-music

# build executable file
go build .
# or
CGO_ENABLED=0 go build .

# run bot
./go-tube
# or
go run .
```
